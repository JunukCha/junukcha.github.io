# junukcha.github.io

Personal academic website of Junuk Cha, built with [al-folio](https://github.com/alshedivat/al-folio).

## Local preview

```bash
docker compose up
```

Then open http://localhost:8080.

- Publications: `_bibliography/papers.bib` (preview images in `assets/img/publication_preview/`)
- About / CV: `_pages/about.md`, `_pages/cv.md`
- News: `_news/`
- Paper project pages: `_pages/project-*.md` with standalone layouts in `_layouts/`
